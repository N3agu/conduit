## Overview
Instead of relying on conventional direct connections that are easily sinkholed or blocked by network boundary controls, Conduit investigates how an agent can dynamically switch communication conduits when primary channels degrade or get filtered.

## Status
This repository is currently undergoing refactoring to unify individual [modules](./modules).
